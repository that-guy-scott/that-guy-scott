# Hi, I'm Scott Angel

**Senior software engineer building business systems, integrations, and automation.**

I work with the people using a system to understand where the work gets slow, repetitive, or unreliable, then build the software to improve it. My work spans applications, data pipelines, practical AI, and the infrastructure needed to keep them running.

I've built systems for libraries, social-service agencies, manufacturers, and small businesses. I like owning the whole path: understand the workflow, trace the data, ship a useful solution, and keep improving it in production.

## Selected work

- **[Patron data synchronization](https://github.com/mcoia/patron-data-to-folio-import)** - Built and owned a MOBIUS pipeline processing 100,000+ patron records nightly into FOLIO through REST APIs. Institution-specific parsers, validation, deduplication, reporting, and audit trails make messy source data manageable.
- **Staff search and operational tools** - Built AI-assisted search over historical support tickets, accessible dashboards, and a Drupal shipping-label generator used daily by member libraries.
- **Client-management software** - Built Hercules CMS with Java, Spring Boot, JSP, and SQL to help social-service agencies manage client records and prepare HUD paperwork and government forms.
- **Manufacturing infrastructure** - Led a nine-month overhaul across three sites, connecting engineering and the shop floor for CAD access and enabling remote IT support.
- **FileUplink** - Built a document-intake application with Next.js, NestJS, AI classification, cloud-storage integrations, background workers, Stripe billing, and AWS ECS/CDK infrastructure.
