# Hi, I'm Scott Angel

I'm a software engineer who likes figuring out how things work and building things that make everyday tasks a little easier.

A lot of my projects start with something slow, repetitive, or awkward: finding a file, moving data between systems, filling out paperwork, or copying the same thing one too many times. I like understanding the problem with the people who deal with it, then making something useful.

I've built software for libraries, social-service agencies, manufacturers, and small businesses. That work has taken me from applications and data pipelines to servers and networks. I enjoy following the whole path, from how someone does their work to what happens to the data behind the scenes.

This GitHub is also a place for smaller tools and things I'm curious about. Sometimes that means experimenting with local AI or writing a Rust utility. Sometimes it means making a visual explanation for my son.

## Things I've made

- **[Patron data synchronization](https://github.com/mcoia/patron-data-to-folio-import)** — A pipeline that makes messy patron data from different institutions usable in FOLIO.
- **[Remove OneDrive](https://github.com/that-guy-scott/remove-onedrive)** — Removes OneDrive from Windows 11 and restores control of your Documents, Desktop, and Pictures folders.
- **[File Indexer](https://github.com/that-guy-scott/file-indexer)** — Search through local source files using Rust, Ollama embeddings, Qdrant, and a browser interface.
- **[MARC Extractor](https://github.com/that-guy-scott/marc_extractor_rs)** — A Rust/PostgreSQL utility for exporting Evergreen catalog records as MARC XML.
- **[Dictator](https://github.com/that-guy-scott/dictator)** — Voice dictation for Linux, using Whisper and Silero voice activity detection.
- **[Copy Paste Extension](https://github.com/that-guy-scott/copy-paste-extension)** — Configurable browser shortcuts for everyday copying and pasting.
- **[Cos & Sin](https://github.com/that-guy-scott/cos-sin)** — A visual explanation I made for my son. This one stays.

## What I like working with

I work across TypeScript, JavaScript, Java, Python, SQL, and Rust, depending on the project. I'm interested in automation, search, and practical uses for AI, including tools that run locally. Linux, Docker, and Bash are part of the mix, along with the infrastructure that keeps everything running.
